# ---------------------------------------------------------------------------
# 1. 需要的三个模型
# ---------------------------------------------------------------------------
#
#   用途               Ollama 名称                  体积        获取方式
#   ----------------   ---------------------------   ---------   ------------------
#   主翻译             Qwen3-14B-Q4KM:latest         8.38 GB     自备 GGUF + create
#   复审 / 总结        Gemma-4-E4B:latest            5.75 GB     自备 GGUF + create
#   快速模式(默认关)   deepseek-r1:1.5b              1.04 GB     ollama pull
#
#   ⚠️ 前两个不是官方 registry 上的公开模型，`ollama pull` 拉不到。
#      它们是本地用 Modelfile 基于 GGUF 创建的自定义命名模型。


# ---------------------------------------------------------------------------
# 2. 目录结构
# ---------------------------------------------------------------------------
#
#   models/
#   ├── gguf/                 （v1.0 无 Modelfile，见下方说明）
#   │   └── （v1.0 未附带 Modelfile，请自行编写，参考 v2.1）
#   └── ollama/               Ollama 模型仓库（OLLAMA_MODELS 指向这里）
#       ├── blobs/
#       └── manifests/registry.ollama.ai/library/
#           ├── Qwen3-14B-Q4KM/latest
#           ├── Gemma-4-E4B/latest
#           └── deepseek-r1/1.5b


# ---------------------------------------------------------------------------
# 3. Modelfile 模板
# ---------------------------------------------------------------------------
#
#   注意：仓库里 models/gguf/Modelfile.qwen3-14b-q4km 的第一行是原作者机器的
#   绝对路径，直接用会失败 —— 必须改成你自己的实际位置。
#
#   ---- Modelfile.qwen3-14b-q4km ----
#   FROM D:/你的路径/Models/Qwen3-14B-Q4KM.gguf
#
#   PARAMETER num_ctx 8192
#   PARAMETER temperature 0
#   -----------------------------------
#
#   Modelfile 里不要写 TEMPLATE：官方 Qwen3 GGUF 自带 Qwen3 的对话模板
#   （约 4.1k 字符，存在 GGUF metadata 里），不覆盖时 Ollama 会自动使用它。
#   正是这个模板让 prompts/*.txt 里的严格 JSON 指令能真正生效。


# ---------------------------------------------------------------------------
# 4. 创建与验证
# ---------------------------------------------------------------------------
#
#   $env:OLLAMA_MODELS = "$PWD\models\ollama"
#
#   ollama create Qwen3-14B-Q4KM:latest -f models\gguf\Modelfile.qwen3-14b-q4km
#   ollama create Gemma-4-E4B:latest     -f models\gguf\Modelfile.gemma-4-e4b
#   ollama pull   deepseek-r1:1.5b
#
#   ollama list
#   # 应能看到上面三个模型


# ---------------------------------------------------------------------------
# 5. 或者复用系统已装的 Ollama
# ---------------------------------------------------------------------------
#
#   如果本机已装 Ollama 并监听 11434，且其模型仓库里已有这三个模型，
#   不设置 OLLAMA_MODELS 就会直接用系统仓库，不必再拷一份。
